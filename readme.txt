** Cómo Ejecutar la Aplicación **

1. Abra el "Simbolo de sistema", "Terminal de Windows".
2. Navegue hasta la carpeta donde se encuentra el archivo Python (Proyecto Final Integrador.py).
3. Ejecute el archivo: python Proyecto Final Integrador.py.

** Funcionalidades Implementadas **
1.Registrar Producto: Permite agregar nuevos productos ingresando nombre, descripción, cantidad, precio y categoría.
2.Mostrar Productos: Lista todos los productos registrados en el inventario.
3.Actualizar Producto: Modifica la cantidad disponible de un producto específico.
4.Eliminar Producto: Elimina un producto del inventario utilizando su ID.
5.Reporte de Bajo Stock: Muestra productos con stock menor a un umbral definido por el usuario.
6.Buscar Producto: Permite buscar productos por nombre o categoría.
7.Menú Interactivo: El usuario puede navegar entre las opciones y decidir si continuar o salir del programa.
